For a much more natural British voice, make a free account at elevenlabs.com, copy your API key from Developers, and paste it here. The free plan covers a limited number of characters per month. Leave blank to use the device voice.

Groq API key

Get one free at console.groq.com. It is saved only in this browser on this device. Never share it or put it in a screenshot.

Sync memory between devices

Saves your notes in a private GitHub Gist so your phone and computer share one memory. Do this once per device with the same token. Create the token at github.com/settings/tokens: Generate new token (classic), tick only "gist", set an expiration, and copy it.
